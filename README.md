# 🧭 Vastu Layout Engine (Web App)

A web-based tool for designing, auditing, and scoring architectural floor plans based on traditional Vastu principles. 

## Tech Stack
* **Frontend:** React.js, Fabric.js (for 2D Canvas layout)
* **Backend:** Node.js/Express (Rules Engine)
* **External APIs:** Google Maps API (for plot orientation)

## How to Run Locally
1. Clone this repository.
2. Open terminal in `/backend` and run `npm install` then `node server.js`.
3. Open terminal in `/frontend` and run `npm install` then `npm start`.
